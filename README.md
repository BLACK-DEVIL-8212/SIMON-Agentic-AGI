## 📖 Overview

**EDIATH** is a production-grade, multi-agent AI system designed to run locally with full autonomy. It combines a voice-enabled UI, a headless backend orchestrator, and local LLM reasoning (GGUF) to deliver a stable, crash-resistant AI experience.

> Built for developers who want **real autonomy** — no cloud dependency, no crashes, no infinite loops.

---

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| 🎙️ **Voice UI + Backend** | Full-duplex voice interface with a robust Python backend. |
| 🧩 **LLM Reasoning (GGUF)** | Local inference using quantized GGUF models — private & fast. |
| 🤖 **Agent Orchestration** | Multi-agent coordination for complex, multi-step tasks. |
| 🛡️ **Graceful Shutdown** | Clean exit handling — no orphaned processes or locked resources. |
| 🔁 **Crash-Resistant** | Built-in loop guards and error recovery. Zero crashes, zero infinite loops. |
| ⚡ **Headless Mode** | Run as a pure backend orchestrator for servers & automation. |
